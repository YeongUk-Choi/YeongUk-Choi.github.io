02   MATERIAL시료와 반사

Δa = 표면 a − 계면 a입니다. 모델의 반사면 법선 방향 유효 격자 간격이 선형으로 변한다고 가정하며, Thickness는 평균 a로 환산합니다.

w는 박막 양 끝의 산란 진폭을 완만하게 줄이는 경험적 테이퍼 폭입니다. σN은 서로 비간섭인 면내 영역들의 정수 두께 분포이며 강도를 평균합니다. 둘 다 0이면 기존 모델입니다. 두 값은 거칠기를 직접 측정한 값이 아니며, 먼저 하나씩 켜서 비교하세요. σN을 켜면 계산 시간이 늘어납니다.

03   SCAN측정과 분해능

각각 면적이 1인 두 Gaussian을 (1 − f)·G(σ) + f·G(mσ)로 섞습니다. f는 넓은 성분의 적분 비율입니다(0.005 = 0.5%). 넓은 성분의 FWHM은 위 FWHM의 m배입니다. f = 0이면 m은 효과가 없고, FWHM = 0이면 두 항목 모두 효과가 없습니다.

이것은 분해능 모양을 기술하는 모델이며, 측정된 기구 함수가 아닙니다. 기판 회절이나 모자이크 등 다른 원인도 비슷한 모양을 만들 수 있어, 피팅 개선만으로 기구가 원인이라고 결론 내릴 수 없습니다.

기울기 0은 상수 배경입니다. 기울기가 있으면 상대 배경은 정규화 전 2θ = 33°의 값이며, b(2θ) = b(33°) × 10^[기울기 × (2θ − 33°)]로 변합니다. 합산한 곡선은 다시 정규화합니다. 상대 배경이 0이면 기울기는 효과가 없습니다.

수직·수평은 산란면 방향이며, 입사광은 완전히 수평 편광되었다고 가정합니다. 조사 길이 옵션은 추가로 1/sinθ를 곱하며, 고정된 입사 빔이 시료 안에 전부 들어오는 경우만 가정합니다. 실제 기하·편광·빔 크기를 확인하세요. 이미 보정한 데이터에는 중복 적용하지 마세요.
