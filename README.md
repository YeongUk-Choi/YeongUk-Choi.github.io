# uk-card-site

QR landing site for UK's business card. Pure static HTML/CSS/JS — no build step, no framework.
Open `index.html` directly or serve the folder with any static host (GitHub Pages, Netlify, university hosting).

## Edit content here (nothing else needs to change)

| File | What it controls |
|---|---|
| `data/profile.js` | name, affiliation, labs, hero sentence and bullet points, "Now" badge, email, home-page photos, calendar embed URL, Google Scholar link, `siteUrl` (QR + link previews) |
| `data/materials.js` | the 14 materials on the periodic table (one entry each; elements, family, dopants, blurb) |
| `data/measurements.js` | measurement/capability list; `featured: true` = home tile + card back; `service: true` = "Available on request" badge |
| `data/focus.js` | Focus one-liner and the Focus page text (light markdown) |
| `data/publications.js` | paper list — generated by `scripts/fetch_publications.py` from a verified DOI list; `image`/`imageCredit`/`featured`/hand-written `abstract` are kept across refreshes |
| `assets/img/` | `portrait.jpg` (square crop) and `portrait-full.jpg`; `pubs/` holds paper figures — CC BY only, credit in `imageCredit` |
| `contact.vcf` | the **Save contact** card — name, role, department, email, site, embedded photo. Hand-written; keep it in step with `data/profile.js` |
| `assets/img/og.jpg` | 1200×630 link-preview card (og tags on every page point at it) |
| `assets/img/qr-site.svg` | the QR the footer shows; vector, so the same file prints on the paper card. Regenerate with `python3 scripts/make_qr.py` |

## Pages

`index.html` (hero + bento) · `schedule.html` · `measurements.html` · `publications.html` · `focus.html` · `materials.html` (periodic table; deep-link with `materials.html#Nb3Sn`) · `ppms.html` (live helium-recondenser readout, `noindex`).

Every page carries a description, canonical URL and og/twitter preview tags, and a footer **Show QR** link — `#qr` on any page opens the QR sheet straight away (bookmark `/#qr` to turn the phone into the card). Without JavaScript the same link opens `assets/img/qr-site.svg` directly.

## Design rules

Near-black background, one violet→orange glow, glass tiles, faint noise. Colour appears in exactly one place per screen (the Focus tile, or the selected material). See `assets/css/site.css` tokens.

## Deploy

Live at https://yeonguk-choi.github.io (GitHub repo `YeongUk-Choi/YeongUk-Choi.github.io`, Pages source = branch `main`, `/`). Every push to `main` republishes the site; `.nojekyll` makes Pages copy files as-is. `.github/workflows/pages.yml` only refreshes `data/publications.js` weekly (Sunday 03:00 KST) and commits it back.

## Publications

Google Scholar blocks automated access and has no API, so it is only the profile link. The DOI list in `scripts/fetch_publications.py` is the source of truth (11 peer-reviewed papers, verified 2026-09-22). Add a paper with `python3 scripts/fetch_publications.py --add <DOI>`. Figures: only CC BY articles are shown with a figure by default; closed-access papers show abstract + DOI until an author-owned image is supplied.
